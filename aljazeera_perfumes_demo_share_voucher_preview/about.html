Prototype purpose

A custom-coded redesign without designing every product page manually.

This prototype converted 177 products from your uploaded Excel export into a front-end demo website. Your developers can connect the same concept to the existing custom backend.

How to use it

1
Approve the direction
Use this as a visual starting point for the redesign.
2
Build reusable components
Header, product card, smart product section, scent bars, notes, comparison.
3
Connect product fields
Add database fields for why_buy, best_for, scent profile, long description, and similar perfumes.

Included product data

The website includes assets/data/products.json and assets/js/products.js. Developers can replace this with real backend API data.

Important note

Some smart fields such as scent profile fields and “avoid if” were generated automatically from available product data. They should be reviewed before publishing on the live website.
